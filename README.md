# CSET 105 Lecture 2: Program Structure

## Lecture Info
This lecture showcases basic built-in functions of JavaScript, & includes the use of packages to implement third-party functions.

## Features
- Operations for checking if 2 values fulfill a given condition
- Adding a custom function using NPM packages
- Creating loops for running repetitive tasks
- Specifying variables to use one or more times later in the program

## Exercises
1. Write a loop that outputs a staircase of characters, creating a right triangle
2. Print numbers from 1 to 100, except replace some numbers under certain conditions with strings
3. Output a grid pattern of characters, & make the size of the grid configurable
4. Print all numbers under certain conditions in ascending order
5. Print all numbers under the same conditions, but in descending order
6. Create a multiplication table with the given parameters
7. Program a simple calculator that can add, subtract, multiply & divide
